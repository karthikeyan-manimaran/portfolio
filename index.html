REC · Tilt test

Hand-tilt test, props off — each motor counter-rotates to keep thrust vertical.

Status — honest version
  • Bench mechanism + low-latency controller: working
  • Indoor IMU-only hover: stable, no visible servo twitch
  • Final hybrid controller: flown; measured results being compiled
01

Problem

On a slope every fixed motor leans with the frame, so the vehicle slides or tips. Articulated landing gear does nothing in flight; tilting rotors aren't used to level thrust on the ground.

02

Approach

  • Four 2-DOF pan-tilt mounts, 3D-printed and bench-verified
  • ROS 2 hybrid tilt controller: IMU-direct + Pixhawk-driven sources, 0.30 s stale fallback
  • Watchdog, altitude lockout, flight-phase state machine
03

Results & failures

  • Latency fixed: MAVLink stream cap, moving average, console logging
  • Yaw drift isolated to two loops correcting the same axes
  • Takeoff crash traced to spin-up vibration → deadbands
